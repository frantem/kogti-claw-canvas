

## Мобильное меню-гамбургер с навигацией по секциям

### Что будет сделано

Добавить фиксированную кнопку-гамбургер в правом верхнем углу экрана (только на мобильных устройствах). При нажатии открывается красивое полноэкранное меню с плавной анимацией и ссылками на все секции страницы. При выборе пункта -- плавный скролл к нужной секции.

### Навигация по секциям

- Главная (`#hero`)
- Услуги (`#services`) -- нужно добавить id в ServicesSection
- Наша команда (`#team`)
- Контакты (`#contact`)
- Как нас найти (`#location`)
- О нас (`#about`)
- Вопросы и ответы (`#faq`)

### Шаги

#### 1. Создать компонент `src/components/MobileMenu.tsx`

- Фиксированная кнопка-гамбургер (z-50) в правом верхнем углу, видна только на `md:hidden`
- Анимированная иконка: три полоски -> крестик при открытии
- При открытии -- полноэкранный оверлей с тёмным полупрозрачным фоном и списком секций
- Плавный скролл (`scrollIntoView({ behavior: 'smooth' })`) при клике на пункт
- Автоматическое закрытие меню после выбора пункта

#### 2. Обновить `src/components/ServicesSection.tsx`

Добавить `id="services"` на корневой `<section>`.

#### 3. Обновить `src/pages/Index.tsx`

Импортировать и добавить `<MobileMenu />` внутрь `<main>`.

### Технические детали

- Используется только CSS + React state, без дополнительных библиотек
- Кнопка полупрозрачная с backdrop-blur для красивого вида поверх Hero
- Меню появляется с анимацией fade + slide
- z-index выше всех остальных элементов
