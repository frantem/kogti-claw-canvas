

## Ускорение загрузки сайта и изображений

### Проблема

Сайт загружает все изображения (мастера, услуги) как полноразмерные PNG файлы без оптимизации. В папке `lovable-uploads` находится 37 PNG-файлов, которые могут весить по несколько мегабайт каждый. Также есть архитектурные проблемы с порядком загрузки.

### Что будет сделано

### 1. Улучшить компонент LazyImage

- Уменьшить `rootMargin` с 200px до 50px -- сейчас изображения начинают загружаться слишком рано, загружая всё сразу
- Добавить CSS `will-change: transform` для плавного появления
- Добавить плавную анимацию появления (fade-in) при загрузке вместо мгновенного показа
- Включить `placeholder` по умолчанию для всех изображений

### 2. Оптимизировать ServicesSection

- Обернуть каждую карточку услуги в собственный IntersectionObserver, чтобы загружать изображения только когда карточка приближается к экрану
- Сейчас все 8 изображений маникюра загружаются одновременно при появлении секции

### 3. Оптимизировать Team (мастера)

- Добавить `placeholder={true}` ко всем изображениям мастеров
- Добавить `loading="lazy"` для изображений которые ниже первого экрана

### 4. Убрать искусственные задержки DeferredSection

- Уменьшить задержки (`delay`) в Index.tsx -- текущие значения 50-350мс добавляют ненужное ожидание после того как секция уже в области видимости
- Оставить IntersectionObserver но убрать setTimeout задержки (установить delay=0)

### 5. Добавить CSS-оптимизации

- Добавить `content-visibility: auto` и `contain-intrinsic-size` для тяжёлых секций -- это позволяет браузеру пропускать рендеринг невидимых секций
- Добавить стили для плавного появления изображений

### 6. Оптимизировать index.html

- Убрать синхронный скрипт Яндекс.Метрики из `<head>` и перенести в конец `<body>` с `async`
- Добавить `font-display: swap` для шрифтов (уже используется `display=swap` в Google Fonts)

---

### Технические детали

**Файлы для редактирования:**

- `src/components/LazyImage.tsx` -- уменьшить rootMargin до 50px, добавить fade-in анимацию при загрузке, включить placeholder по умолчанию
- `src/components/ServicesSection.tsx` -- убедиться что каждое изображение услуги загружается лениво через LazyImage с placeholder
- `src/components/Team.tsx` -- добавить placeholder={true} к изображениям мастеров
- `src/pages/Index.tsx` -- убрать/уменьшить delay в DeferredSection (все delay=0)
- `src/index.css` -- добавить CSS content-visibility: auto для секций, стили fade-in анимации
- `index.html` -- перенести скрипт Яндекс.Метрики из head в конец body

**Ожидаемый результат:**
- Первая загрузка страницы ускорится на 30-50%
- Изображения будут загружаться только когда пользователь прокручивает к ним
- Меньше одновременных сетевых запросов
- Плавное появление изображений вместо "мигания"
