

## Автоматическое сжатие изображений при загрузке через админ-панель

### Текущая ситуация

- Изображения услуг **захардкожены** в `ServicesSection.tsx` и не управляются через админ-панель
- Компонент `ImageUpload` (используется для мастеров, фавиконки, OG-картинки) загружает файлы в Supabase Storage **без сжатия** -- как есть
- Одноразовое сжатие было применено только к 12 существующим изображениям услуг

### Решение: клиентское сжатие перед загрузкой

Добавить сжатие и конвертацию в WebP прямо в браузере перед отправкой в Supabase Storage. Это будет работать для **всех** загрузок через `ImageUpload`.

### Шаги

#### 1. Добавить утилиту сжатия изображений

Создать `src/lib/imageCompression.ts` -- функция, которая через Canvas API:
- Уменьшает изображение до заданного максимального размера (по умолчанию 800px)
- Конвертирует в WebP с качеством 80%
- Возвращает сжатый File-объект

#### 2. Обновить `ImageUpload.tsx`

Перед вызовом `supabase.storage.upload()` пропускать файл через функцию сжатия. Расширение файла автоматически станет `.webp`.

### Технические детали

- Canvas API поддерживается всеми современными браузерами
- WebP поддерживается во всех современных браузерах (включая Safari 14+)
- Сжатие происходит на клиенте -- не нужен сервер или edge function
- Работает для всех изображений: мастера, фавиконка, OG, и любые будущие загрузки

### Файлы
- `src/lib/imageCompression.ts` -- новая утилита
- `src/components/admin/ImageUpload.tsx` -- интеграция сжатия
