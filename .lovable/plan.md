

## Эффект "левитации" карточки записи над фоном

### Проблема
Белая карточка с кнопками "Записаться" и "Позвонить" визуально сливается с фоном — нет ощущения глубины и отделения от фоновой фотографии.

### Решение
Усилить тень, добавить лёгкое свечение и полупрозрачность, чтобы карточка выглядела парящей над фоном.

### Изменения в `src/components/BookingCard.tsx`

Заменить стили корневого `div`:
- Усилить `shadow-2xl` до кастомной многослойной тени (мягкая + резкая)
- Добавить `ring` для тонкой границы-свечения
- Слегка уменьшить непрозрачность фона (`bg-white/90`) для эффекта стекла
- Усилить `backdrop-blur`

Примерные классы:
```
bg-white/90 backdrop-blur-2xl rounded-[4rem] p-6 
shadow-[0_8px_40px_rgba(0,0,0,0.25),0_2px_10px_rgba(0,0,0,0.1)] 
ring-1 ring-white/30 border border-white/20
```

Один файл: `src/components/BookingCard.tsx` — только изменение классов корневого контейнера.
