## Цель
Вывести kogtistudio.by в ТОП-1 Google и Яндекс по запросу «маникюр Витебск» и связанным ключам за ~2 месяца.

⚠️ Честно: ТОП-1 за 2 месяца в конкурентной локальной нише — амбициозная цель. Реалистично — войти в ТОП-10 за 2 месяца и бороться за ТОП-3 к 3-4 месяцу. Гарантировать позицию №1 не может никто, но план ниже даёт максимальные шансы.

## Часть 1. Google Search Console — что делать вам

Файл подтверждения уже лежит в `public/google167a50f33cc6cee7.html`. После публикации сайта:

1. Откройте Google Search Console → нажмите **«Подтвердить»** на странице с HTML-файлом.
2. После подтверждения добавьте sitemap: GSC → **Sitemaps** → введите `sitemap.xml` → Submit.
3. Запросите индексацию главной: **URL Inspection** → вставьте `https://kogtistudio.by/` → **Request Indexing**. Повторите для `/privacy`.
4. То же самое в **Яндекс.Вебмастере**: добавить сайт (файл `yandex_dac1b23bf2daa320.html` уже есть), отправить sitemap, переобход страниц.

## Часть 2. Что я сделаю в коде (технический SEO)

### A. Расширю sitemap.xml якорными разделами
Добавлю URL с якорями (`#services`, `#team`, `#faq`, `#location`, `#contact`) — это поможет Google показывать sitelinks под главным результатом.

### B. Усилю структурированные данные (Schema.org)
В `src/pages/Index.tsx`:
- **LocalBusiness** вместо `BeautySalon` (или вместе) — с точным адресом, координатами, часами работы, телефоном, ценовым диапазоном, `areaServed: Витебск`.
- **Service** schema для каждой ключевой услуги (маникюр, педикюр, наращивание) с ценами.
- **BreadcrumbList** для главной.
- **Review/AggregateRating** — если есть реальные отзывы.
- Исправлю телефон в Schema (сейчас `+375 (29) 123-45-67` — заглушка, а реальный `+375 (33) 658-26-39`).

### C. Семантика и контент на главной
- Добавлю H1 с точным вхождением «Маникюр в Витебске» (если ещё нет, проверю Hero).
- Усилю alt-теги изображений с ключами («маникюр Витебск», «педикюр Витебск», имена мастеров).
- Добавлю микро-блок с ключевыми услугами и ценами в текстовом виде (важно для Яндекса).
- Внутренняя перелинковка между секциями.

### D. Технические улучшения
- Добавлю `hreflang="ru-BY"` (сейчас только `ru`).
- Проверю `<h1>` — он должен быть один и содержать главный ключ.
- Добавлю Open Graph image размером 1200x630 (если нет реального — сгенерирую с логотипом и текстом).
- Sitemap: проставлю свежий `lastmod` и `image:image` теги для каждой страницы.

### E. Performance (Core Web Vitals — фактор ранжирования)
- Проверю LCP/CLS на главной через preview.
- Если нужно — оптимизирую загрузку Hero-изображения.
